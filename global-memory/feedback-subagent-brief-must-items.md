给子代理写任务书时，**必须完成项只留可验证的实质**（文件落盘、内容齐、真跑留档），
外观/规模类要求（「落在 200—300 行」这类）明确写成**只用于事后点名**，超了不拦、在报告里说明即可。

**Why:** 2026-09-28 CodeWeave S10 批次，5 个代理里有 2 个（写 Vue 与 C 编译链那两笔）在 150 回合上限被截断，
截断点都恰好是「正在把文件裁进我给的行数区间」——内容其实已经写完了，却把回合和自报都耗在裁行上，
主代理只能自己复量结构 + 反查留档来代替报告。

**How to apply:** 写任务书的「必须完成项」那一节时自检一遍：这条是**实质**还是**外观**？
外观一律降级为「超了点名」。同理还有「不许改 frontmatter」「保持两份围栏逐字节一致」这种是实质（能当场验）；
「建议 100—140 行」是外观。另外派单前要数**跨文件一致性**（上一批的教训：单元与它自己的练习页契约文件名不一致，
任何门禁都扫不到，代理照旧口径写完就产出「照跟做做完却交不出契约文件名」的题）。
与 [[feedback-subagent-hygiene]]、[[feedback-verify-subagent-file-claims]] 一起用。
