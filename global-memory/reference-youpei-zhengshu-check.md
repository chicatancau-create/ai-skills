评优材料核查（`H:\下载\25级移动应用开发二班评优*`）用户确认的口径，2026-09-22 定、09-23 补充。

## 口径
- **评分表 .xlsx 绝对只读**，佐证材料是被核对方。评分表没有"总分"单元格，各项得分在 E 列（合并单元格对应一个 B 列大项）。
- 佐证正文全在表格里：`对应××素质第N点加X分` 是大节，下面跟小节标题+截图。**大节数字不可靠，以小节合计对评分表 E 列**。
- 小节标注接在原标题后面（如 `杰出校友讲座校级加1分`），四类写法：
  1. 讲座/活动类（德育3、智育2、体艺4、劳育3）→ `校级加1分` / `院级加0.5分`
  2. 个人获评荣誉（德育5、智育4、体艺6、劳育5）→ 按档次反推：1 分=院级、2 分=校级、3 分=省级
  3. 集体荣誉/比赛获奖（体艺7、劳育4）→ 1 分=校级、0.5 分=院级
  4. 无级别档的（党校团校、学生干部、献血、英语等级、寝室卫生、志愿时长、社会实践）→ 只写 `加X分`，不硬套级别
- **志愿时长：1 小时 = 0.1 分**（评分表模板写"每满10小时+1分"要按此理解），逐项分数向下取一位小数。
- 同名活动在不同人材料里级别可能不同——各自评分表该项总分锁定的。冲突时**以本人评分表该项总分为准**。
- "两个标题在上、两张图在下"的排版很常见，标题后没紧跟图 ≠ 缺图，按顺序 1:1 对应后再判定。

## 有效手法
- **图片按 md5 比对**能硬判定"是不是同一场活动"：同一张照片出现在两人材料里，级别标注就必须一致。这是查级别标注错标最有力的手段（`pip install pillow` 后可用 PIL 拼 contact sheet，一次读多张截图，省大量往返）。
