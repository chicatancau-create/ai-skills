# 规则：备份/回滚目录统一归口 G:\数据备份

> 建立于 2026-11-25，用户明确要求。

## 规则

- 本机的**备份、回滚、历史快照**一律放在 G:\数据备份\ 下，不要再散落在业务工作区里。
- 原 G:\CodeWeave\工作区\data\迁移回滚\ 已整体移入 G:\数据备份\迁移回滚\（2026-11-25，同卷重命名 0.12 秒）。
- 以后再有「迁移回滚」类需求，直接在 G:\数据备份\ 里做，不要放回 工作区\data\。
- G:\CodeWeave\工作区\data\ 现在只放运行态数据：
untime、待核对数据、迁移记录。

## 为什么

用户原话（2026-11-25）：「这两个东西合成一个文件夹，数据备份放到数据备份那里面，迁移回滚以后，在数据备份中迁移。」
即：备份类内容要有单一归口，便于统一管理和清理。
