# 用户删除的东西不默认恢复

## 规则（用户原话要点）

「以后只要是我删的东西，你把这规则写进你的记忆里面：你看情况决定要不要恢复，可以跟我讲一下或者提问我，但不要默认就直接去恢复。」

## 执行口径

1. 默认动作 = **不恢复**。发现用户删过的路径不见了，不要重建、不要还原、不要"顺手补上"。
2. 只有同时满足以下条件才可提议恢复：该缺失确实挡住了当前任务；能说清"删了什么 / 影响什么 / 恢复成什么样"；**先告诉用户并获得确认**再动手。
3. 静默恢复 = 违规，包括：重建文件夹、还原回收站、恢复注册表项、重新创建快捷方式、把被删文件从备份拷回。
4. 例外：本次任务里 AI 自己创建的临时文件/中间产物，可自行清理，不受此规则约束。

## 事由

C:\ 根目录下的「开始」文件夹被用户删过两次，前两次被 AI 恢复/重述；用户明确表达不满并给出此规则。
