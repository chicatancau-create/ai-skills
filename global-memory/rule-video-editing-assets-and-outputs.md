# 规则：剪辑工具/素材放 D 盘，成品视频放 H 盘，原地不留成品

- 来源：用户 2026-11-28（m03336）：「你的那些剪辑工具全部放在D盘，用于剪辑的东西全部放D盘。……那你就会把本次内容完全放进H盘剪映当中的那个成品里面……你把原先地方的那些呃东西全删了。就是成品视频删了，然后你要保留那些能重复利用的东西，尽量避免空间的挤占，因为的话，D盘快满了，而H还有空间」
- **三层分工（硬规则）**：
  1. **工具层 → D 盘**：剪辑/渲染脚本、Python venv、FFmpeg 与模型、渲染中间目录（seg/mix.wav/video_silent）、BGM 素材库、配音 wav。统一在 `D:\AI-Tool-State\<任务>\` 下。`D:\Models\` 放模型权重（见 rule-models-store-in-d-models.md）。
  2. **可复用资产 → D 盘 + 工作区归档**：EDL/timeline.json、ass/srt 字幕、体检 json、封面 jpg、片头片尾模板 mp4 与生成脚本。这些体积小（MB 级），G 盘任务夹里也要留一份。
  3. **成品视频 → H 盘 `H:\视频\成品\<内容名>\`**（2026-11-28 用户明确要求新建正式成品目录，并定「按内容单独成册、各册独立」）：册内固定 `成片\`（mp4）/ `封面\`（横屏·竖屏·通用三张）/ `发布\`（发布文案 + `_清单_成品MD5.csv`）。**同一部剧不同集各自独立成册**（`瑞克和莫蒂S01E02精讲\`、`…S01E03精讲\`），不合并进剧集总目录，避免单集重发牵连其他集。目录规则写在该目录的 `README_成品目录规则.md`。
- **原地清空交付物**：成品 mp4 拷到 H 盘、**四件逐个 MD5 与源比对一致后**，再删 D 盘输出目录与 G 盘归档里的 mp4。D 盘/工作区只留文本与小图资产。
- **不要误删的两类**：①CapCut 草稿引用的源媒体（删了草稿丢素材，见 rule-workspace-no-videos.md 的例外条款）②`_env` venv（57k 文件 7.7GB，重装要几小时）。
- **H 盘「剪映成品」目录的实况（2026-11-28 核实并已处置）**：核实当时 H 盘**没有**名为「剪映」或「成品」的目录，本机也只装了 CapCut（`D:\CapCut\CapCut.exe` 9.8.0.4213）、没有 JianyingPro；当时先按既有导出习惯落 `H:\视频\CopCut\`，用户随后同意**新建正式目录** `H:\视频\成品\`，交付已迁入。`H:\视频\CopCut\` 保留用户自己的两个历史成片，不要动。
- 操作提示：拷完必须跑 `Get-FileHash -Algorithm MD5` 双向比对，MD5 一致才删源；删后复核目标目录文件数/总体积。
