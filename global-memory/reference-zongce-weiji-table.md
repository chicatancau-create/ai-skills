25级移动应用2班（移应二班）综测违纪表的固定口径，老师（田依宁老师）定的规则：

- 违纪范围：晚归、夜不归寝、上课/集合迟到、早退、旷课、寝室卫生不合格、其他不配合班级管理。**已履行请假手续的外宿/回家不算违纪**。
- 寝室卫生扣分：**第一学年（2025—2026）只计大扫除期间的扣分；第二学年起抽查与大扫除都计**，要区分开。
- 卫生可**以寝室为单位**登记，但要列全寝名单；**混寝要甄别责任班级，不是本班的不记本班**。同一寝室多次不合格须按学工系统逐次列日期（周报只有周次，准确日期只能查学工系统）。
- 模板列：班级｜姓名｜电话｜违纪日期（xx年x月x日）｜情况说明｜处理结果｜备注。

数据源（均在 `H:\下载\`）：
- `25级移应二班周报`/`移应二班周报（第N周）.docx` —— 违纪只在正文「四、黑榜」「五、考勤榜」；**里面的图片是优秀寝室照片，不是违纪截图**。
- `田依宁老师宿舍总表(1).xlsx` —— 每寝「优秀次数/不合格次数」，是找周报漏记的依据。注意 4 人间计数在 F/G 列，6 人间漂到 H/I 列。
- 周报正文的周次标题常是从旧文件复制的（写「第九周」实为第十四周），**以日期为准，别信文件名里的周次**；文件名带 `(1)` 的是下学期。

用户要求：表里**只列本班人员**（外班同学不写进名单），备注保持一行短标签；没有确切日期的直接写「时间未确定」，不要留「待学工系统核实」这类占位；源表里明显笔误的电话（位数不对、与他人完全同号）按同号段作最小改动修掉，**别编得太抽象**（不要 13800000000 那种），改后要告知哪些号是假造的。
