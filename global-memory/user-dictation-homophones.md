用户的指令里高频出现**近音字、错字、口语简称**，不是笔误偶发，而是稳定习惯：

- 「带复合」→ **待复核**（同音 dài fùhé）
- 「云度」→ 站点实名是 **云渡**（yundu.lol）
- 「开头的那个文件夹」→ 指 **E:\DeskBox**（他的快捷启动盒）
- 「AI 盘」→ 他放项目的盘（`G:\CodeWeave` 等）
- 「梯子/梯子的内核」→ Clash Verge 的 `verge-mihomo` 核心
- 「绅士」→ 他书签里那个不可触碰的目录名（见 [[feedback-private-folder-and-no-delete]]）

**How to apply:** 遇到可疑词先用数据自证歧义（列目录、查书签树/History/注册表、按名字搜站点），
把"我理解成 X，依据是 Y"写在结论里，而不是发问打断他 —— 他明确说过没空、要我按最优解自己走。
只有当歧义会导致不可逆动作（删文件、改系统目录）时才确认。
判死链/失效同理：他说"这个没用了"往往指**内容**没了，先量文件字节/解析/HTTP 状态再定性。
