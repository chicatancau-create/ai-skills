- 用户 2026-11-22（m01335）：「我没说让你尽量短，我只是说让你平淡一点……时间不重要，重要的是平淡一点，仅此而已」；「那个语气是突然上调的，你突然就把它转掉了……上调的话你突然截断了就感觉特别抽象」。

- 落地规则（今后一切 vlog/视频剪辑任务）：
  1. **平淡是唯一优化目标**，时长不优化、能长能短服从叙事；不要为「短」剪掉内容。
  2. 切点必须落在 silencedetect 实测静音锚点内（句尾落下后 ≥0.25s 才切、下句起调前 ≥0.25s 进）；**语气上调的句子一律让它说完**；连续独白宁可整段不内切。
  3. 停顿两侧的切点不加音频淡化（淡化截语气=突兀）；afade 只用于环境声床接落，宽度 ≤0.4s 防静音洞。
  4. 字幕稀疏、逐字按原话（whisper large-v3 词级校对），被剪掉音频的句子不留字幕（幻影字幕）；语气词保留=自然呼吸。
  5. 转场只用叠化遮同机位跳切；同镜头续接不挂转场（鬼影）。
  6. 交付确认后清场：成品与中间产物删除/落 D 盘，工作区不留视频（见 rule-workspace-no-videos.md）。
