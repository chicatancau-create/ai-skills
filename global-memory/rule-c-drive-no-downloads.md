# C 盘不放下载实体

## 规则（用户原话要点）

「一般在 H 盘里有个『下载』文件夹，通常都放在那里。记住，C 盘当中不包含任何下载的内容，除非是缓存。如果是缓存的话可以存留，因为只存一会儿，只要下载实体不放在 C 盘即可。」

## 执行口径

1. **C 盘（含 C:\ 根目录、用户目录）不得存放下载实体**：安装包、视频、压缩包、镜像、迅雷/浏览器/网盘的下载产物一律不放 C。
2. **下载落点默认 H:\下载**（用户已有的下载文件夹）；H 盘不存在该目录时再问。
3. **缓存可以留**：浏览器/应用缓存、临时文件（只需存在一会儿的）允许在 C，不必清理、不必搬走。
4. 发现 C 盘有下载实体时：先报告清单与体积，给出去向建议（H:\下载\…），**由用户决定**再动；不擅自删除、也不擅自搬移。
5. 与「用户删的东西不默认恢复」配套：用户已删掉的 C 盘下载目录（如 C:\开始\迅雷下载）不得重建。

## 事由

C:\ 根目录「开始」文件夹下曾有「迅雷下载」，用户指出它不该在 C 盘并已自行删除两次。
